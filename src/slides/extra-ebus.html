Dynamic weighted sampling / EBUS

The sampling primitive behind the graph algorithm.

Maintain the endpoint distribution.

Group weights by exponent; maintain bucket lists and summaries.

EBUS selects vertices. The graph algorithm handles edge insertions and deletions.

Two sampling levels

1. Select a bucket using bounded-word summaries and an exact rounding correction.

2. Propose an index inside the bucket, then apply rejection sampling.

A structural illustration, not a browser implementation of EBUS bit arithmetic.

Move one weight, not the entire table.

The index changes bucket; update the affected summaries.

In our graph update: temporarily set to sample , then restore the new weight .
